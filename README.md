# Encrypted Chat App

A real-time multi-client chat application developed using Java socket programming and multithreading.

## Features
- Real-time messaging
- Multi-client support
- Java Swing GUI
- Client-server architecture
- AES encryption
- Modular folder structure

## Technologies Used
- Java
- Socket Programming
- Multithreading
- Java Swing
- MySQL
- AES Encryption

## Project Structure
- client/
- server/
- security/
- model/
- database/

## Future Improvements
- User authentication
- Persistent chat history
- Online users list
- Private messaging
